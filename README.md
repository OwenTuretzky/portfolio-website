# My Personal Website

My personal website and portfolio for showcasing computer science projects and my photography portfolio.

Live at [owen.turetzky.org](https://owen.turetzky.org)

## Built with
* [Astro](https://astro.build/)
* Custom CSS and HTML
* Vanilla Javascript

## Running Locally

1. Clone the repo:
```bash
git clone https://github.com/OwenTuretzky/portfolio-website.git
cd portfolio-website
```
2. Install dependencies:
```bash
npm install
```
3. Start the local server:
```bash
npm run dev
```
